# LeaferJS Poster · 社交货币海报生成器

> 把对一件作品的自然语言描述，做成一张**用户指定比例、可直接发布**的海报。
> 交付物是严格 JSON 协议里的单文件 HTML，由 [LeaferJS](https://www.leaferjs.com/) 绘制，比例自适应、静态、可截图导出。

## 这是什么

本仓库是一套**面向大模型的平面海报生成提示词**（`appPrompt.md`）及其配套页面。它把模型组织成一支七人设计团队：

- **艺术总监**：创意方向、主视觉、记忆点；敢于删
- **传播策划**：判断这张图凭什么被转发
- **平面设计师**：网格、层级、动线、留白、版面平衡
- **字体设计师**：字体、字号、字重、字距、行距、断行、对齐
- **视觉艺术家**：色彩、材质、图形语言、艺术表现
- **LeaferJS 技术导演**：画布、场景树、图形、文字、适配、清晰度
- **QA**：按清单逐条验收，不合格就重做

核心判断标准只有一句：**这张图配得上创作者的主页。** 它不是作品说明书，而是一件社交货币 —— 三秒内让人知道「这个作品有点意思、做图的人有审美、我想扫一下看看」。

## 交付协议（硬约束）

模型必须**只输出一个合法 JSON 对象**，前后不允许任何解释文字、Markdown 代码围栏或注释。顶层字段：

| 字段 | 类型 | 约束 |
| --- | --- | --- |
| `type` | `string` | 固定为 `poster` |
| `height` | `number` | 画布高度（设计单位） |
| `width` | `number` | 画布宽度（设计单位） |
| `title` | `string` | 作品名，≤ 16 字；超长只缩写，不改写作品名 |
| `description` | `string` | 一句话说明这张海报画了什么，≤ 30 字，不换行 |
| `code` | `string` | 完整单文件 HTML，源码 180–380 行，以 `<!DOCTYPE html>` 开头、`</html>` 结尾 |
| `highlights` | `string[3]` | 恰好 3 条，每条 ≤ 20 字；写设计记忆点，不写功能点 |

结构示意（`code` 已省略）：

```json
{
  "type": "poster",
  "height": 1200,
  "width": 900,
  "title": "折叠的城市",
  "description": "一张被反复折叠又展开的城市地图。",
  "code": "<!DOCTYPE html> ... </html>",
  "highlights": [
    "标题压住折痕的偏心构图",
    "单色墨线 + 一处朱红强调",
    "右下角白色二维码展签"
  ]
}
```

### `code` 字段的转义铁律

`code` 的值本身是一段 JSON 字符串。为了不让裸双引号提前结束字符串，提示词要求：

1. `code` 源码内**零双引号**：HTML 属性、JS 字符串、CSS 字体名全部用单引号，插值用反引号模板字符串。
2. `code` 源码内**零反斜杠**：不写 `\n`、`\t`、`\u`、正则转义或 `<\/script>`；换行用 `String.fromCharCode(10)` 或拆成多个 `Text` 元素。
3. URL 中的单引号写成 `%27`、反斜杠写成 `%5C`，不要靠转义绕过规则。
4. JSON 序列化时真实换行写成 `\n`；禁止尾随逗号、注释与代码围栏。

## 链接与展签

需求中含 `http://` 或 `https://` 链接时，先判定展示方式，再谈设计（判定只做一次，写死在代码常量里）：

| 模式 | 适用 | 表现 |
| --- | --- | --- |
| `qr` | 页面链接，或用户明确要扫码 | 加载 `qr-code-styling`，绘制可扫描二维码 + 扫码提示 |
| `hero` | 链接是作品图 / 封面 / 主图 | 图片占据主视觉区，不加载二维码库 |
| `slot` | 链接是 logo / 图标 / 头像 / 二维码图 | 图片进入右下展签位，按类型决定是否保留扫码提示 |
| 无链接 | — | 不加载二维码库，不画二维码，不用装饰方块占位 |

链接图片必须走「位图 → blob → `L.Image` → 画布」，禁止外链图片、`<img>` 或 CSS 背景图，避免污染画布导致导出失败。

## 技术栈

- **运行时**：原生 HTML / CSS / JavaScript，单文件，无打包、无框架
- **渲染引擎**：`LeaferJS 2.3.4`
  `https://unpkg.com/leafer-ui@2.3.4/dist/web.min.js`
- **可选依赖**：仅 `qr` 模式加载 `https://transweb.cn/common/qr-code-styling.js`
- **画布**：短边 900 设计单位，`pixelRatio: 3`；`stage` 等比缩放居中，只改 `scale/x/y`
- **可用图形**：`Rect`、`Ellipse`、`Polygon`、`Star`、`Text`、`Group`、`Image`（仅链接位图）
- **文字单位**：`fontSize` / `letterSpacing` / `lineHeight` 全部是像素（`lineHeight` 不是倍数）
- **导出**：由查看器截图完成，画布外内容不会进入导出图

## 快速开始

### 1. 准备提示词

将 [`appPrompt.md`](./appPrompt.md) 全文作为**系统提示词**（System Prompt）交给支持长输出的模型。它包含十准则、交付格式、运行契约、版式系统、字体规范、构图色彩、反模式与验收清单。

### 2. 提出需求

用一句自然语言描述作品与海报诉求，例如：

> 为「手写体生成器」做一张 4:5 的小红书海报，作品是把一句话变成书法，链接是 https://example.com/writing 。

提示词会自动判定比例（`4:5`）、链接展示方式（`qr`）与版式族（竖版），**不会反问用户**。

### 3. 解析 JSON 并落盘

```js
const fs = require('fs');
const data = JSON.parse(responseText);
fs.writeFileSync('poster.html', data.code, 'utf8');
console.log(data.title, data.width + '×' + data.height);
```

### 4. 打开并导出

用浏览器打开 `poster.html`。海报会按比例完整居中显示；截图保存画布区域即可得到成品。

## 设计标准摘要

### 社交货币十准则

1. **作品优先**：画作品本身，不画 AI 技术。
2. **非凡优先**：只放大最值得惊叹的一处，其余卖点删掉。
3. **身份表达**：版面克制、细节精确、作者清楚。
4. **差异化**：按作品气质选风格，不套模板。
5. **视觉证据**：画真实产物、交互帧、数字；界面作品做几何重构而非贴截图。
6. **情绪驱动**：主视觉只制造一种情绪。
7. **故事传播**：让人能用一句话说清「把什么变成什么」。
8. **荣誉可视化**：真实数据才转成编号、计数、日期、刻度。
9. **低成本分享**：标题、描述、作者、链接四件套完整。
10. **品牌一致**：同一作者共享边距、字体与展签基因。

### 版面纪律

- 标题下沿与主视觉上沿 ≥ 24；主视觉下沿与描述上沿 ≥ 36。
- 边距固定 72；竖版 6 栏、栏距 24；基线单位 12。
- 主视觉可破格、可出血，文字不可以。
- 没有链接时删掉展签与扫码提示，空出的右下保持安静。
- 一个主视觉、一个视觉入口、一个记忆点；同时存在的视觉重点不超过两个。

### 设计反模式（命中即改）

- 机器人、芯片、大脑、电路板、蓝紫霓虹、发光粒子、悬浮玻璃卡片、手机 mockup。
- 纯黑 `#000` / 纯白 `#fff`（链接展签卡除外）、彩虹渐变、五个以上色相。
- 贴界面截图冒充主视觉；编造数据；把标题当说明书。
- 每张海报都套同一种风格；用装饰填满留白。

## 交付验收清单

- [ ] `code` 源码内双引号数量为 0、反斜杠数量为 0
- [ ] 画布比例与需求一致，误差 ≤ 1 设计单位
- [ ] 短边 ≥ 900 设计单位，`pixelRatio: 3`
- [ ] 所有视觉元素都在 canvas 内
- [ ] 主视觉第一眼可辨，且只承担一个隐喻
- [ ] 标题逐字使用作品名，断行合理，无孤字
- [ ] 描述、作者、展签位置符合 4.1 锚点
- [ ] `qr` 二维码可扫描且指向用户链接；`hero` / `slot` 图片未裁切变形
- [ ] 文字对比度达标，未缩字
- [ ] 无 `requestAnimationFrame`、无动画、无页面级 UI
- [ ] 无控制台异常、无 404 资源

## 已知限制

- 依赖 `unpkg.com` CDN；二维码模式还依赖 `transweb.cn` 的 `qr-code-styling` 脚本。
- 单次生成 180–380 行，仍可能被小上下文模型截断。
- 画布导出依赖查看器截图，本页面不提供下载按钮。
- 提示词内示例只用于学习格式与工程结构，不应照抄版式与配色。
